# 0.2.0 验证记录

验证日期：2026-10-03。运行基础为 Java 17 / Minecraft 1.20.1 / Forge 47.3.22。

## 已完成

- Java 17 编译和生产重混淆构建通过。
- 独立 Forge 专用服务器启动成功，无客户端类加载异常。
- 32 项真实服务器运行探针通过：8 个配方、手册注册、射击伤害与弹药、耐久与熵债、冷却、墙壁遮挡、无弹药、中继互动充能、无信号停机、有信号脉冲、燃料 NBT、死亡回声、世界 NBT、回声回收、阶段、净化消耗、净化耐久、净化冷却、零熵不扣材料、缺燃料不生效、射击和净化任务保存、经验不能重复领取、任务保存于死亡后保留的玩家数据。
- 从 PCL 交付 ZIP 解压出一个全新实例运行生产客户端，检查自研主菜单、离线协议终端、单人世界加载和状态同步。
- 另用临时 ClientSmoke 探针验证真实玩家物品、任务自动完成、服务器数据同步、HUD 与世界内原生终端渲染；日志出现 `AP_CLIENT_SMOKE_SUCCESS`。截图位于 `docs/images/`。
- 发布包只包含自研 JAR；检查全部资源 JSON、字节码版本、唯一作者主页、Forge/Minecraft 依赖、ZIP CRC 和 SHA-256。
- 发布 JAR 不含 RuntimeProbe；测试源码使用显式 `-PruntimeProbe` 才编入临时测试 JAR。

## 范围与限制

本次客户端运行测试使用 Linux 环境。Windows PCL 拖入导入及用户实际硬件上的运行需要用户验证，不能声称已自动测试其界面。采用 PCL 支持的 CurseForge manifest + overrides 结构，且安装包内置核心 JAR；首次安装仍需要启动器下载 Minecraft / Forge / 原版依赖。

本项目没有重做旧第三方整合包的所有功能。原生玩法、任务、净化器和界面已实现，联机状态同步在单人内置服务器路径验证；多客户端独立连接尚未测试。旧 0.1.x 衍生试验包与其存档不作为本次兼容性承诺。

## 范围与限制

本次客户端运行测试使用 Linux 环境。Windows PCL 拖入导入及用户实际硬件上的运行需要用户验证，不能声称已自动测试其界面。采用 PCL 支持的 CurseForge manifest + overrides 结构，且安装包内置核心 JAR；首次安装仍需要启动器下载 Minecraft / Forge / 原版依赖。

本项目没有重做旧第三方整合包的所有功能。原生玩法、任务、净化器和界面已实现，联机状态同步在单人内置服务器路径验证；多客户端独立连接尚未测试。旧 0.1.x 衍生试验包与其存档不作为本次兼容性承诺。

## 0.2.1 修复

## 0.2.2 全屏布局与交付

教程改为居中且尺寸受视口限制的面板；章节、正文、状态与返回键在同一面板中，长正文可滚动并裁剪。新安装默认自动GUI缩放。窗口与2560×1440大窗口分别检查自动缩放及GUI=2旧设置，所有按钮必须在视口内。交付ZIP根目录直接放未修改PCL EXE，无启动BAT。

# 原创大型玩法验收目标

用户授权持续开发，直到内容达到大型整合包的体验规模。不能以ZIP体积、重复素材或仅增加物品颜色作为完成标准。

本次按可游玩系统验收：

- 主线从基础生存、农业补给、材料加工、自动化，到跨维度遗迹、八阶守卫、基地复苏与后期工程，至少六条互相连接的生产/探索路线。
- 80项以上有真实条件、持久化和奖励的目标；支持旧24项进度迁移，不能用超过32位的目标互相覆盖。
- 两个原创探索维度，至少12类原创区域，18处有不同布局/资源/挑战用途的遗迹与设施。
- 16种敌人，包含八个具备可辨识技能和阶段的首领；新的首领要通过旧链继续解锁。
- 至少18台可实际加工或修复的机器，多输入加工、红石暂停、漏斗自动输入/输出、库存保存和拆除返还、满仓保护。
- 八种可种植作物，食物、治疗、防护和远征补给，以及三条后期制造路线；新增道具都必须在生存中获得。
- 分阶段装备、武器与工具，后期不是单纯反复等待同一个数值上涨。
- 玩家能在游戏内阅读完整配方/加工说明和目标；发布包统一包含PCL、指南、源码和资源，仍可拖入PCL。
- 真正生成测试、机器与自动化测试、目标高位持久化/同步测试、客户端界面/维度往返测试，以及原有玩法回归都通过后再作为大型版本发布。

以上是对大型内容的可检验定义，不声称一套自研玩法等价于落幕曲所有第三方MOD的功能总和。实施完成前不把阶段包当最终交付。

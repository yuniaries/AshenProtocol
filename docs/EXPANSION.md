# 原创扩展：失落坐标

目标：把短工具链扩展成探索—加工—装备—守卫—区域复苏循环。落幕曲只作为内容规模参考，不复制其模组清单、任务文本、结构、资源或代码。

这次实现的发布范围：72个新增物品条目（含方块物品与刷怪蛋）、五种维度矿石、六处自然生成遗迹、六台可保存并掉落库存的加工/修复设备、三套护甲与分阶段工具武器、四种普通敌人与四个具备阶段技能的首领、四阶召唤钥匙、24项持久化目标，以及可在生存中使用的遗迹定位器、含六类群系的失序领域与可往返的坐标门。基础游戏的模型骨架与音效会注明来源，自研材质和玩法代码归本项目。

路线：主世界灰烬矿 → 压制/结晶 → 灰烬哨站守卫 → 潮汐遗迹 → 冰原/沙漠资源 → 下界裂隙 → 末地坐标核心 → 区域修复网络。每阶钥匙必须使用上一阶段材料；遗迹箱子提供补充资源，不直接跳过首领链。

验收：生产包可启动，数据包解析无错误，矿石/结构可生成与定位，机器支持输入/输出/燃料/满仓/断电/保存/拆除，首领技能与战利品有效，旧八章进度兼容，新目标有真实触发条件，源码与可导入PCL包统一交付。

这里的数量是实现范围，不代表一个自研MOD已经等同于数百个第三方MOD多年积累的内容量。后续大型化需要在真实游玩基础上继续扩展，此文件不替代当前代码验收。
